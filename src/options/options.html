Connect GitHub

How to get a Client ID (one time, ~2 min)
  1. Open github.com/settings/applications/new
  2. Application name: CPGitSync  ·  Homepage URL: your repo URL (anything works)
  3. Authorization callback URL: put your repo URL (device flow doesn't use it, but the field is required)
  4. ✅ Check "Enable Device Flow" — this is required.
  5. Click Register application, then copy the Client ID and paste it above.

Advanced — use a token instead
